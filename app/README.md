# Frontend

The React/Vite client uses Solana Kit for RPC status checks and Wallet Adapter
for wallet connection and transaction signing. Listing reads and writes go
directly between the browser and the Anchor program; backend sign-in is not
required.

The app loads the generated IDL from `public/idl/ad_marketplace.json`,
discovers Auction and ListingMetadata PDAs from Solana RPC, and supports
listing creation, metadata initialization for older listings, admin KYB
verification, bidding, buyout, and supplier claims. Names and descriptions are
public on-chain metadata. The **My bids** tab includes listings owned by the
connected supplier wallet as well as listings where it currently leads.

A bid that meets or exceeds a listing's buyout price permanently closes the
listing. The bidder pays exactly the configured price; any overage and the
displaced leader's bid are refunded atomically. A zero buyout price disables
this behavior. Completed-cycle settlement remains lazy and occurs only during
a later successful bid or claim transaction.

The app supports Localnet (the default) and Devnet. Localnet is restricted to a
loopback RPC. Devnet requires HTTPS, and its RPC genesis hash is checked before
program state is read or a transaction is submitted. The program ID is selected
from `VITE_AUCTION_PROGRAM_ID`; it matches the IDL generated by Anchor.

To build and deploy locally, run `pnpm run anchor:build:localnet` and
`pnpm run anchor:deploy:localnet` from the repository root. The build command
syncs the generated IDL into the app. Copy `.env.example` to `.env` and connect
a wallet configured for the local validator.

## Devnet

The program is not usable on Devnet until it has been deployed. Use a wallet
dedicated to testing, fund it with Devnet SOL from a faucet, and run these
commands in the Dev Container:

```sh
pnpm run anchor:build:devnet
solana airdrop 2 <DEPLOYER_PUBLIC_KEY> --url https://api.devnet.solana.com
solana balance <DEPLOYER_PUBLIC_KEY> --url https://api.devnet.solana.com
pnpm run anchor:deploy:devnet
```

The deployment may require more than one faucet request, depending on the
program binary size and current Devnet faucet limits. The deployer pays only
with test SOL. After deployment, set `app/.env` to:

```dotenv
VITE_SOLANA_CLUSTER=devnet
VITE_SOLANA_RPC_URL=https://api.devnet.solana.com
VITE_AUCTION_PROGRAM_ID=5dKLaVXqzR6Ja4GpkfseLCuPGDdnUFZ4cs6YkUSzMTdF
```

Restart Vite after changing `.env`. The first wallet to initialize the Devnet
config becomes the KYB admin, and the program has no admin-transfer
instruction; confirm the intended wallet before initializing it.

To smoke-test the deployed program by creating a listing, set
`ANCHOR_PROVIDER_URL=https://api.devnet.solana.com` and
`ANCHOR_WALLET=<path-to-funded-test-wallet>` in the shell, then run
`pnpm run test:devnet`. The test checks the configured RPC and executable
program before submitting a transaction.

Run the app from the workspace root:

```sh
pnpm --filter @ad-marketplace/app dev
```
